Проектирование движка скидок
Учебный проект «Маркетплейс "Штучки-Дрючки"».
Описание
Проект представляет собой движок расчёта скидок для заказа. Движок получает заказ и список настроенных скидок, применяет подходящие скидки в установленном порядке и возвращает итоговую стоимость заказа и информацию о применённых скидках.
Типы скидок
В проекте реализованы:
Процентная скидка.
Фиксированная скидка при достижении порога.
«3 по цене 2» для выбранной категории.
Промокод с процентной или фиксированной скидкой.
Скидка за лояльность.
Бесплатная доставка при превышении порога.
Скидка за первый заказ.
Порядок применения скидок
Скидки применяются в следующем порядке:
«3 по цене 2».
Процентные скидки.
Фиксированные скидки.
Бесплатная доставка.
Промокод с процентной скидкой сравнивается с обычной процентной скидкой. Выбирается большая выгода, а при равной выгоде выбирается промокод.
Архитектура
Discount
Общий базовый класс для всех скидок. Каждая конкретная скидка наследуется от него и реализует свой метод apply().
DiscountFactory
Фабрика создаёт нужный объект скидки по её типу из конфигурации. Благодаря этому PricingEngine не создаёт конкретные классы скидок самостоятельно.
ConfigProvider предоставляет конфигурацию скидок. Конфигурация хранится отдельно от логики расчёта.
DiscountContext
Контекст содержит текущее состояние расчёта: текущую сумму товаров, стоимость доставки, заказ и список применённых скидок.
PricingEngine
Главный класс расчёта. Он применяет переданные скидки в правильном порядке и формирует результат.
Округление
Денежные значения округляются до копеек методом банковского округления.
Округление выполняется после применения каждой скидки и при формировании итоговых денежных значений.
